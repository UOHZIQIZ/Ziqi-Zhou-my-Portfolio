Project 3

Final Project 3 Design

In this project, I used Makey Makey and p5.js to create a fun audio game, an interactive experience that combines real-world touch with digital animation. The user can control the buttons on the screen by touching a physical object connected to Makey Makey (corresponding to the left, up, down, and right arrow keys).
My inspiration comes from the painting of Monet. A sound effect is triggered when the user accurately hits the falling flower note. I implemented the global dynamic color shift by using p5.js HSB color system. As the game continues to accumulate, the color of each frame of the background will change subtly, creating a dreamy, smart light and shadow effect.
