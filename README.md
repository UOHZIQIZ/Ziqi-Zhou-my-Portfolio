# Ziqi Zhou — Interaction Design Portfolio

Complete static website. No installation or build command is required.

## Publish with GitHub Pages

1. Extract this ZIP. Upload the extracted files, not the ZIP itself.
2. Put `index.html` at the repository root.
3. Commit and push the files using GitHub Desktop.
4. In GitHub, open Settings > Pages.
5. Choose Deploy from a branch, main, and /(root), then Save.

## Source files

- `index.html`: page structure and English fallback text.
- `css/`: website styles, layout, colors and photo animation.
- `js/main.js`: navigation, language selection and project rendering.
- `js/data.js`, `js/vdc-data.js`, `js/art-data.js`: portfolio content and translations.
- `js/portrait-gallery.js`: animated three-photo stack.
- `js/flora.js`, `js/diagrams.js`: canvas and diagram helpers still referenced by the app.
- `projects/`: the supplied project websites.
- `images/`, `videos/`, `files/`: images, videos, project PDFs and resume.

The default language is English. Existing visitor language preferences are remembered.
Chinese and other translations remain intentionally available through the language menu.
External fonts, embedded content and external resources require an internet connection.
